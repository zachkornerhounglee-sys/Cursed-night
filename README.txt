CURSED NIGHT v17 — v8 LOOK + CO-OP
==================================
This is your v8 game (original look, original menus) with the working co-op layer added on top.

UPDATE YOUR GITHUB PAGES SITE
1. Extract this ZIP and open the CursedNight_v17 folder.
2. In your repo: Add file > Upload files, drag in index.html and game.html (not the outer folder). Commit to main.
3. Wait ~1 minute, then hard-refresh (Ctrl+Shift+R) or use a private window so the old cached copy is gone.

PLAY WITH FRIENDS
1. Host: open your Pages link > CO-OP MULTIPLAYER > Create room > Copy invite link.
2. Friends open that link and connect automatically. Host presses Start run.
3. The host's browser relays everyone's data, so the host should keep the game tab open.

IF SOMEONE CAN'T CONNECT
Some networks (school, work, some mobile data) block direct browser-to-browser traffic. Try another network or a phone hotspot.
See PATCH_NOTES_v17.txt for adding your own free TURN relay (CNMP_TURN).
